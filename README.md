# SSN — Semantic Sensor Network Ontology

**A mirror. Not maintained by Ontoshire.**

Published by the W3C and OGC. This repository contains **no RDF** — only an `ontoshire.ttl`
naming the publisher's own canonical URL, which Ontoshire fetches unchanged
when a version is published.

| | |
|---|---|
| Source | <https://www.w3.org/ns/ssn/> |
| Ontology IRI | `http://www.w3.org/ns/ssn/` |
| Licence | [W3C Software and Document Licence](http://www.w3.org/Consortium/Legal/2015/copyright-software-and-document) |

Mirrored so the ontology is discoverable alongside others. The bytes are
always the publisher's, and the published version records a checksum of
exactly what was fetched.

SSN declares `owl:imports <http://www.w3.org/ns/sosa/>`, so once the SOSA mirror is published this dependency resolves within Ontoshire rather than showing as external.

If you maintain this ontology and would rather it were not mirrored here,
[tell us](mailto:enquiries@ontoshire.com) and it will be removed.
